# KeyLinkLister

**Click a linked Mythic Keystone in chat → one button lists a Premade Group for that dungeon.**

World of Warcraft addon (Midnight 12.1). When a friend links their keystone and you click it, a button appears under the tooltip:

- **List group: Dungeon +N** — creates the Premade Group listing for that dungeon (title auto-generated by the server, playstyle from the button on the right).
- **Re-list for: …** — you already have a listing for another dungeon: it is replaced.
- **Open panel** — you are solo and don't own that keystone (a friend linked it and left): the server refuses API listings without the key, so the button opens Blizzard's "Start a Group" panel with the dungeon and playstyle pre-selected and the cursor in the Title field. Blizzard blocks addons from writing that field (`securityDisableSetText`), so the suggested title (default `+<level>`) is shown as placeholder and in chat: type it and press **Enter** (the addon maps Enter in the Title field to List Group). Authenticator required for custom titles. The Details field is locked the same way (`SetSecurityDisableSetText` in Blizzard's mixin).
- In a party without owning the key, the addon tries the direct listing first (the key holder may be in your group); if the server refuses, the next click opens the panel.
- Disabled with a reason when you are not the group leader, the group is full, you are in an instance group, or (accounts without an authenticator) you don't own that keystone — the same rules as the Blizzard Group Finder.

## Commands

| Command | Effect |
|---|---|
| `/kl` or `/keylinklister` | help |
| `/kl playstyle [1-4]` | show or set the listing playstyle (1 Learning … 4 Expert/Competitive) |
| `/kl xfaction` / `private` / `open` | toggle cross-faction listing, private group, open Group Finder after listing |
| `/kl mode direct\|panel` | list from the button, or always open the create-group panel |
| `/kl score <n>` | required M+ rating for applicants |
| `/kl title <format>` | suggested title for keys you don't own (default `+%d`; `%s` = playstyle, e.g. `+%d %s`) |
| `/kl log [n]` / `diag` / `debug` / `logclear` | diagnostic log: print, copyable window, live chat echo, wipe (also saved in `KeyLinkListerDB.log`) |
| `/kl delist` | remove your active listing |
| `/kl status` | current settings |
| `/kl test [mapID level]` | self-check against Blizzard's own keystone→activity mapping and show the button for a keystone |
